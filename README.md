# 🤖 bot_rust

Telegram-бот, который следит за коммитами разработчиков игры **Rust** на [commits.facepunch.com](https://commits.facepunch.com), пересказывает их понятным русским языком с помощью локальной нейросети и публикует в Telegram-канал после модерации.

> Название игры: [Rust](https://rust.facepunch.com), от Facepunch Studios. К языку программирования Rust проект отношения не имеет, бот написан на Python.

## Возможности

- **Парсинг коммитов.** Каждые 45 секунд бот проверяет сайт и находит новые коммиты (автор, текст, дата, ссылка).
- **Пересказ через ИИ.** Текст коммита отправляется в локальную модель **Ollama** (по умолчанию `llama3.1:8b`), которая объясняет на русском, что изменилось в игре, без технического жаргона.
- **Скриншоты.** Через Playwright (headless Chromium) делается скриншот нужного коммита и прикладывается к посту.
- **Модерация в Telegram.** Новый пост приходит модератору в личку с кнопками: ✅ одобрить, ❌ отклонить, ✏ редактировать текст, 🖼 добавить своё фото.
- **Автопубликация.** Режим включается из меню бота, и посты уходят в канал без ручного одобрения.
- **Очередь постов.** Просмотр списка постов на модерации, удаление одного или всех.
- **Ежедневный отчёт.** В заданное время бот отправляет в канал сводку за сутки (сейчас текст шаблонный).
- **Защита от дублей.** Обработанные коммиты хранятся в SQLite (`commits.db`).

## Как это устроено

```
commits.facepunch.com ──► parser ──► Ollama (пересказ) ──► модерация ──► Telegram-канал
                                                              ▲
                                       скриншот (Playwright) ─┘
```

```
.
├── main.py                 # точка входа, фоновые задачи (парсинг, ежедневный отчёт)
├── config.py               # настройки (секреты берутся из .env)
├── parser/commits_parser.py  # парсинг сайта (aiohttp + BeautifulSoup)
├── ai/ollama_client.py     # запросы к Ollama
├── telegram/
│   ├── moderation.py       # меню, кнопки, FSM-сценарии модерации
│   └── publisher.py        # публикация в канал
├── storage/database.py     # SQLite: учёт обработанных коммитов
└── utils/                  # форматирование поста, логи, скриншоты
```

## Стек

Python 3.12, aiogram 3, aiohttp, BeautifulSoup4, Playwright, SQLite, Ollama.

## Установка и запуск

### 1. Подготовка

- Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
- Создай канал и добавь бота администратором с правом публикации.
- Узнай свой chat ID (например, через [@userinfobot](https://t.me/userinfobot)) и ID канала (начинается с `-100`).
- Установи [Ollama](https://ollama.com) и скачай модель:

```bash
ollama pull llama3.1:8b
```

### 2. Проект

```bash
git clone https://github.com/niktodrugoi/bot_rust.git
cd bot_rust

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install -r requirements.txt
playwright install chromium
```

### 3. Настройки

Скопируй `.env.example` в `.env` и заполни:

```env
BOT_TOKEN=токен_от_BotFather
MODERATOR_CHAT_ID=твой_chat_id
CHANNEL_ID=-100xxxxxxxxxx
```

Файл `.env` добавлен в `.gitignore`, так что токен не попадёт в репозиторий.

Остальное меняется в `config.py`: модель Ollama (`OLLAMA_MODEL`), промпт для пересказа (`OLLAMA_PROMPT`), время ежедневного отчёта (`DAILY_REPORT_HOUR`, в UTC).

### 4. Запуск

Убедись, что Ollama запущена, затем:

```bash
python main.py
```

После старта модератору придёт главное меню бота.

## Управление

Всё управление идёт через inline-кнопки в личке с ботом:

| Кнопка | Действие |
|---|---|
| 🔄 Проверить новые коммиты | Запустить проверку сайта вручную |
| 📋 Список на модерации | Все посты, ожидающие решения |
| 📭 Последний пост | Показать последний пост из очереди |
| Автопубликация: Вкл/Выкл | Переключить режим публикации без модерации |
| ❓ Помощь | Краткая справка |

## Безопасность

Никогда не коммить токен бота. Если токен случайно попал в публичный репозиторий, сразу перевыпусти его в @BotFather командой `/revoke`.

## Идеи для развития

- Настоящая статистика в ежедневном отчёте (сейчас шаблонный текст)
- Docker-образ для быстрого запуска
- Фильтрация малозначимых коммитов
- Перевод настроек парсинга в `.env`
